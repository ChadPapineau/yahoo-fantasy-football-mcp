## Closing summary

**What survived unchanged** — the log's own list (§ Closing verdict): the architecture and layering; SQLite via `node:sqlite`; XML + the one path builder; the limiter/cache/envelope/error contract and the terminal `NOT_PROVISIONED` rule; `oob` auth; the `FantasyPlatform` seam, now used by four implementations; the scoring engine and its property set; the Skills-versus-tools split, eval lanes, fixture rules, launchd design and `ff_` naming; the phasing *shape*; the confirmation gate's **mechanics**.

**What changed, in one line each:**
1. A calendar and a fallback: Phase 1a (Yahoo-free, starts on plan approval) / 1b (Yahoo); the application ahead of the review with a dated decision gate; both ends of L stated; X1 (`ManualLeagueProvider`) and X2 (`SleeperProvider`) named; a 1a-minimum cut as Chad's choice.
2. Every security claim names the *session condition* for which it holds; writes are unsupported in any reach session; Keychain is hygiene, not proof; no plaintext pending file; TTY-only CLI channels; XML entity expansion explicitly off (the library default was verified inverted).
3. Analytics say what they are: nflverse-fed v1 lines; `Dist.basis`; `mean` default until `pwin` proves itself; an n-aware retrospective; local (not product-wide) degradation on a scoring mismatch.
4. The token economy budgets definitions: `FF_TOOLSET=core` default; no `outputSchema` on large lists; bare path-listed player names; the untrusted-text rule served once in `instructions` with a pointer per tool; downward-only ceilings; two client spikes instead of assumptions.
5. The storage layer does what its tests assert: Node ≥ 24.15; consistent backups; bounded lock waits; per-source dataset files published by `rename()` and attached read-only; every performance bound names its data size.
6. Repo and process: no required checks on `main` until PRs are required; `docs.yml` proven against the future `.npmrc`; the full transitive allow-list with a maintained-line rule; the recommendation log treated as an injection source; `live` folded into `start-sit`.

**Residuals the plan carries openly** (ranked in the log's closing verdict): Yahoo's answer; the unmeasured size of L; whether v1 analytics beat "last week's points"; the two client spikes; reach-session detection is a heuristic; five build-time [U]s, each with a fallback; and the plan is unbuilt — its tests are the next adversary.
